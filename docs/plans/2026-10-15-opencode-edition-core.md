# OpenCode edition, plan 1 (core) — Implementation Plan

> **For agentic workers:** run with `/orchestrate` on this file (Dryas). Each `## Task N:` section is self-contained: its Goal/Scope/Done/Failing-test lines are the `.orchestrate/PLAN.md` contract; Interfaces and Steps follow. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship the core of the Dryas OpenCode edition: rules, process skills, commands, executor agents with the tier ladder, the `jev` MCP server, the scope lock and the Jev gate (with a real user prompt on `ask`), an installer, a release check, end-to-end tests against a real OpenCode, and the docs.

**Architecture:** `opencode/` is a new edition laid out as it is installed into an OpenCode config dir. A sync tool renders it from `claude/` and `codex/`. One hand-written TS plugin (`opencode/plugin/dryas.ts`) maps OpenCode hooks onto the existing Python hook chain (`chain.py --harness opencode`); the chain decides, the plugin translates. The installer copies `opencode/` into the config dir and records what it wrote.

**Tech Stack:** Python 3.9+ stdlib (chain, sync, installer, tests with pytest/unittest); TypeScript run by OpenCode's own runtime (the plugin); OpenCode 1.18 plugin API and HTTP server (`opencode serve`) for the end-to-end tests; GitHub Actions.

**Spec:** `docs/specs/2026-10-15-opencode-edition-design.md` (step 1 rows only; step 2 is plan 2).

## Global Constraints

- Python 3.9+, standard library only, in the chain, the sync tool, the installer and the tests (pytest is the runner).
- OpenCode floor: `1.18.0`. CI pins `opencode-ai@1.18.32`; a weekly job runs `opencode-ai@latest`.
- No Node, npm or Bun install for users: the plugin is a `.ts` file OpenCode runs itself. CI may use npm to install OpenCode.
- Setup never edits the user's `opencode.json`; the plugin's `config` hook adds the `jev` MCP server and the permission settings at load.
- Every file stays under 500 lines (`tools/release_check.py` is already over: add OpenCode code in a new module).
- Files under `opencode/` other than `opencode/plugin/dryas.ts` and `opencode/skill/dryas-{orchestrate,interrogate,benchmark-checklist}/SKILL.md` are generated by `python tools/sync_opencode.py`; never edit them by hand.
- Executor tiers in logs, Jev questions and thresholds keep the slot names: fast = `haiku`, standard = `sonnet`, strong = `opus`, frontier = `fable`.
- OpenCode MCP tool names are `jev_<tool>` (`jev_jev_judge`, `jev_memory_search`, `jev_log_dispatch`).
- Full test command: `python -m pytest -q claude/jev/tests install/tests`; plus `python tools/sync_codex_plugin.py --check` and `python tools/inventory.py --check` (0 problems).
- Never commit `.orchestrate/`. Commits: Conventional Commits, explicit paths.

## Review Focus

1. A user `opencode.json` whose `permission.bash` (or `edit`) holds an `"ask"` rule: Dryas must not auto-answer prompts for that key, so the user's own asks still reach them (Task 5 test `test_user_ask_rule_is_kept`).
2. Python missing or `DRYAS_PY` wrong: OpenCode must keep working and edits must go through, like a failing Claude Code hook (Task 5 test `test_broken_python_fails_open`).
3. Re-running setup after the user edited an installed command: the edit is kept as `<file>.dryas-old` and the new file written (Task 6 test `test_edited_file_kept_as_old_on_rerun`).
4. A user's own `command/commit.md` (or any file setup did not write) in the config dir: setup refuses and changes nothing (Task 6 test `test_refuses_foreign_file`).
5. A Windows Python path in `install.json`: written with forward slashes so the plugin can spawn it (Task 6 test `test_record_py_forward_slashes`).

```python
#!/usr/bin/env python3
"""Render the OpenCode edition (opencode/) from claude/ and codex/, its sources of truth.
  python tools/sync_opencode.py           write opencode/
  python tools/sync_opencode.py --check   list drift and leaked Claude or Codex names, exit 1 if any (CI)
tools/sync_codex_plugin.py runs this too. opencode/ is laid out as installed into an OpenCode config dir. The shim
(opencode/plugin/) and the SKILL.md of the HAND skills are written by hand; this tool never touches them.
"""
import argparse
import json
import re
import shutil
import sys
from pathlib import Path
from typing import Dict, List, Optional, Union

sys.path.insert(0, str(Path(__file__).resolve().parent))
import sync_codex_plugin as scp  # noqa: E402

REPO = scp.REPO
MARK = "<!-- dryas-managed -->"
TREES = (("claude/jev", "opencode/dryas/jev"), ("claude/pstack", "opencode/dryas/pstack"))
HAND = ("orchestrate", "interrogate", "benchmark-checklist")  # opencode/skill/dryas-<name>/SKILL.md, hand-written
CLAUDE_ONLY = ("ruflo-tools.md",)  # skill reference files OpenCode has no use for (no Ruflo on OpenCode)
THIN = ("orchestrate", "interrogate")  # commands that only load the skill of the same name
FROM_CODEX = ("wplan", "wreview", "commit", "tune", "retro")  # commands rendered from codex/skills/<name>
TIERS = ("fast", "standard", "strong", "frontier")
JEV_TOOLS = ("jev_judge|log_override|log_escalation|log_dispatch|log_review|log_merge|memory_search|memory_store|"
             "memory_list|memory_forget|swarm_init")
_NAMES = (
    (re.compile(r'"\$\{CLAUDE_PLUGIN_ROOT\}/bin/dryas-py"'), '"<dryas-py>" -X utf8'),
    (re.compile(r"(?:\$\{CLAUDE_PLUGIN_ROOT\}|<dryas-root>)/skills/([a-z][a-z-]*)/"), r"<dryas-root>/../skill/dryas-\1/"),
    (re.compile(r"(?:\$\{CLAUDE_PLUGIN_ROOT\}|<dryas-root>)/commands/"), "<dryas-root>/../command/"),
    (re.compile(r"\$\{CLAUDE_PLUGIN_ROOT\}"), "<dryas-root>"),
    (re.compile(r"mcp__plugin_dryas_jev__"), "jev_"),
    (re.compile(r" \(server `jev`\)"), ""),
    (re.compile(r"`(" + JEV_TOOLS + r")`"), r"`jev_\1`"),
    (re.compile(r"the Dryas hooks are not trusted: tell the user to run /hooks in Codex and stop"),
     "the Dryas plugin did not load: tell the user to re-run install.sh --harness opencode and stop"),
    (re.compile(r"\$dryas:(" + "|".join(scp.COMMANDS) + r")\b"), r"/\1"),
    (re.compile(r"\$dryas:([a-z][a-z-]*)"), r"dryas-\1"),
    (re.compile(r"(?<![\w$/.@-])dryas:([a-z][a-z-]*)"), r"dryas-\1"),
    (re.compile(r"Codex sub-agents?"), "OpenCode subagents"),
    (re.compile(r"\bCodex\b"), "OpenCode"),
)
_LEAK = re.compile(r"\$dryas:|mcp__|\$\{CLAUDE_PLUGIN_ROOT\}|^<!-- /?(?:claude|codex|opencode) -->", re.M)
RULES_TAIL = (
    "## OpenCode notes\n"
    "- Executors are the subagents `dryas-executor-fast`, `dryas-executor-standard`, `dryas-executor-strong` and "
    "`dryas-executor-frontier` (dispatch them with the task tool). Logs and thresholds keep the slot names `haiku`, "
    "`sonnet`, `opus` and `fable` for them.\n"
    "- Not yet on OpenCode: context-window warnings, compaction keep/restore, `/handoff` and the memory hooks "
    "(plan 2 of the edition). Call `jev_memory_search` and `jev_memory_store` yourself.\n")


def names(text: str) -> str:
    for pat, rep in _NAMES:
        text = pat.sub(rep, text)
    return text


def _field(text: str, key: str) -> str:
    m = scp._FRONT.match(text)
    f = re.search(r"^%s:\s*(.*)$" % re.escape(key), m.group(1), re.M) if m else None
    return f.group(1).strip().strip('"') if f else ""


def _body(text: str) -> str:
    m = scp._FRONT.match(text)
    return text[m.end():] if m else text


def render_skill(text: str, name: str) -> str:
    text = scp.harness_blocks(text, "opencode")
    return ("---\nname: dryas-%s\ndescription: %s\n---\n%s\n" % (name, json.dumps(names(_field(text, "description"))), MARK)
            + names(_body(text)))


def render_command(name: str, codex_skill: str) -> str:
    desc = json.dumps(names(_field(codex_skill, "description")))
    if name in THIN:
        body = "Load the `dryas-%s` skill with the skill tool and follow it for: $ARGUMENTS\n" % name
    else:
        body = names(_body(codex_skill)).strip() + "\n\nArguments: $ARGUMENTS\n"
    return "---\ndescription: %s\n---\n%s\n%s" % (desc, MARK, body)


def render_agent(executor: str, tier: str) -> str:
    desc = json.dumps("%s Tier: %s." % (_field(executor, "description"), tier))
    return "---\ndescription: %s\nmode: subagent\nmodel: {{MODEL}}\n---\n%s\n" % (desc, MARK) + names(_body(executor))


def render_rules(codex_rules: str) -> str:
    text = re.sub(r"## Not available in Codex\n.*\Z", "", codex_rules, flags=re.S).rstrip() + "\n\n"
    return names(text) + RULES_TAIL


def plan(repo: Path) -> Dict[str, Union[Path, str]]:
    """Target rel path (posix, from the repo root) -> source file (copied) or text (rendered)."""
    repo, out = Path(repo), {}  # type: ignore[var-annotated]
    for src, dst in TREES:
        for rel, f in scp._files(repo / src):
            out[(Path(dst) / rel).as_posix()] = f
    out["opencode/dryas/AGENTS.md.template"] = render_rules(scp._lf(repo / "codex/AGENTS.md.template"))
    skills = repo / "claude/skills"
    for n in scp.SKILL_FILES:
        if (skills / n).is_file():
            out["opencode/skill/" + n] = scp._lf(skills / n)
    for name in scp.PROCESS_SKILLS + HAND:
        for f in sorted((skills / name).glob("*.md")) if (skills / name).is_dir() else []:
            if (name in HAND and f.name == "SKILL.md") or f.name in CLAUDE_ONLY:
                continue
            try:
                text = scp._lf(f)
                out["opencode/skill/dryas-%s/%s" % (name, f.name)] = (
                    render_skill(text, name) if f.name == "SKILL.md" else names(scp.harness_blocks(text, "opencode")))
            except ValueError as e:
                raise ValueError("%s: %s" % (f.relative_to(repo).as_posix(), e))
    for name in THIN + FROM_CODEX:
        out["opencode/command/%s.md" % name] = render_command(name, scp._lf(repo / "codex/skills" / name / "SKILL.md"))
    executor = scp._lf(repo / "claude/agents/executor.md")
    for tier in TIERS:
        out["opencode/agent/dryas-executor-%s.md" % tier] = render_agent(executor, tier)
    return out


def _existing(repo: Path) -> List[str]:
    """Every file in the generated part of opencode/ (strays included), except caches and hand-written files."""
    base, out = Path(repo) / "opencode", []
    hand = {"dryas-" + h for h in HAND}
    for sub in ("dryas", "skill", "command", "agent"):
        for f in sorted((base / sub).rglob("*")) if (base / sub).is_dir() else []:
            parts = f.relative_to(base).parts
            if f.is_dir() or f.suffix == ".pyc" or any(p in scp.CACHE_DIRS for p in parts):
                continue
            if parts[0] == "skill" and len(parts) == 3 and parts[1] in hand and parts[2] == "SKILL.md":
                continue
            out.append(f.relative_to(Path(repo)).as_posix())
    return out


def drift(repo: Path) -> List[str]:
    want, out = plan(repo), []
    for rel, src in want.items():
        dest = Path(repo) / rel
        if not dest.is_file():
            out.append("missing " + rel)
        elif (scp._lf(dest) != src) if isinstance(src, str) else not scp._same(src, dest):
            out.append("differs " + rel)
    out += ["extra " + rel for rel in _existing(repo) if rel not in want]
    return sorted(out)


def leaks(repo: Path) -> List[str]:
    """One line per rendered file that still names a Claude or Codex construct."""
    out = []
    for rel, src in sorted(plan(repo).items()):
        m = _LEAK.search(src) if isinstance(src, str) else None
        if m:
            out.append("leak %s: %s" % (rel, m.group(0)))
    return out


def sync(repo: Path) -> List[str]:
    want, changed = plan(repo), []
    for line in drift(repo):
        kind, rel = line.split(" ", 1)
        dest = Path(repo) / rel
        if kind == "extra":
            dest.unlink()
        else:
            dest.parent.mkdir(parents=True, exist_ok=True)
            src = want[rel]
            if isinstance(src, str):
                dest.write_bytes(src.encode("utf-8"))
            else:
                shutil.copy2(str(src), str(dest))
        changed.append(rel)
    return changed


def run(repo: Path, check: bool) -> int:
    if not check:
        for rel in sync(repo):
            print("synced " + rel)
        return 0
    bad = drift(repo) + leaks(repo)
    for line in bad:
        print(line)
    if bad:
        print("opencode/ is out of date or leaks names: fix the source or tools/sync_opencode.py, run "
              "python tools/sync_opencode.py and commit the result")
    return 1 if bad else 0


def main(argv: Optional[List[str]] = None) -> int:
    ap = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    ap.add_argument("--check", action="store_true")
    ap.add_argument("--repo", default=str(REPO))
    a = ap.parse_args(argv)
    try:
        return run(Path(a.repo), a.check)
    except ValueError as e:
        print("error: %s" % e)
        return 1


if __name__ == "__main__":
    sys.exit(main())
```

```python
                                     headers={"content-type": "application/json"})

        for _ in range(240):
            try:
                self._http("GET", "/session", timeout=2)
                return
            except Exception:
                time.sleep(0.5)
        raise RuntimeError("opencode serve did not start; see %s" % (self.tmp / "serve.log"))

    def _listen(self):
        try:
            with urllib.request.urlopen(self._base + "/event" + self._q, timeout=900) as r:
                for raw in r:
                    line = raw.decode("utf-8", "replace").strip()
                    if line.startswith("data:"):
                        try:
                            self.events.append(json.loads(line[5:]))
                        except ValueError:
                            pass
        except Exception:
            pass

        out = []
        for msg in self._http("GET", "/session/%s/message" % sid) or []:
            for p in msg.get("parts", []):
                if p.get("type") == "tool":
                    st = p.get("state", {})
                    out.append((p.get("tool"), st.get("status"), str(st.get("error") or st.get("output") or "")))
        return out

    def children(self, sid: str) -> List[str]:
        return [c["id"] for c in self._http("GET", "/session/%s/children" % sid) or []]

    def asked(self, sid: str, timeout: float = 20.0) -> Optional[dict]:
        end = time.time() + timeout
        while time.time() < end:
            for ev in list(self.events):
                if ev.get("type") == "permission.asked" and ev.get("properties", {}).get("sessionID") == sid:
                    return ev["properties"]
            time.sleep(0.3)
        return None

    def reply(self, sid: str, permission_id: str, response: str) -> None:
        self._http("POST", "/session/%s/permissions/%s" % (sid, permission_id), {"response": response})

    def requests(self) -> List[dict]:
        return [json.loads(l) for l in self._log.read_text(encoding="utf-8").splitlines() if l.strip()]

    def close(self) -> None:
        for p in (self._srv, self._mock):
            p.terminate()
            try:
                p.wait(timeout=15)
            except subprocess.TimeoutExpired:
                p.kill()
        self._serve_log.close()
```

```ts
// Runs one Dryas script with `input` as JSON on stdin; resolves to its stdout, or "" on any failure or timeout.
function runScript(script: string, args: string[], input: unknown, timeoutMs: number): Promise<string> {
  return new Promise((resolve) => {
    let out = ""
    let settled = false
    const finish = (v: string) => {
      if (!settled) {
        settled = true
        clearTimeout(timer)
        resolve(v)
      }
    }
    const child = spawn(PY, ["-X", "utf8", join(ROOT, "jev", script), ...args], { stdio: ["pipe", "pipe", "ignore"] })
    const timer = setTimeout(() => {
      child.kill()
      finish("")
    }, timeoutMs)
    child.stdout.on("data", (d) => (out += d))
    child.on("error", () => finish(""))
    child.on("close", () => finish(out))
    child.stdin.on("error", () => {})
    child.stdin.end(JSON.stringify(input))
  })
}

// OpenCode tool call -> Claude-shaped tool_name and tool_input; null for tools the chain does not judge.
function toolEvent(tool: string, args: any): { tool_name: string; tool_input: Record<string, unknown> } | null {
  const a = args ?? {}
  switch (tool) {
    case "bash":
      return { tool_name: "Bash", tool_input: { command: String(a.command ?? ""), description: a.description } }
    case "write":
      return { tool_name: "Write", tool_input: { file_path: a.filePath, content: String(a.content ?? "") } }
    case "edit":
      return { tool_name: "Edit", tool_input: { file_path: a.filePath, old_string: String(a.oldString ?? ""), new_string: String(a.newString ?? "") } }
    case "multiedit":
      return {
        tool_name: "MultiEdit",
        tool_input: {
          file_path: a.filePath,
          edits: (Array.isArray(a.edits) ? a.edits : []).map((e: any) => ({ old_string: String(e?.oldString ?? ""), new_string: String(e?.newString ?? "") })),
        },
      }
    case "patch":
    case "apply_patch":
      return { tool_name: "apply_patch", tool_input: { command: String(a.patchText ?? a.patch ?? "") } }
  }
  return null
}

function hasAsk(v: unknown): boolean {
  if (v === "ask") return true
  return !!v && typeof v === "object" && Object.values(v as object).some((x) => x === "ask")
}

function toAsk(v: unknown): unknown {
  if (v === undefined || v === "allow") return "ask"
  if (v && typeof v === "object") return Object.fromEntries(Object.entries(v as object).map(([k, x]) => [k, x === "allow" ? "ask" : x]))
  return v
}

// Mutates `perm`; returns the keys whose prompts the shim may answer (the user set no "ask" there).
function gatePermissions(perm: Record<string, unknown>): string[] {
  const answerable: string[] = []
  for (const k of GATED_KEYS) {
    if (!hasAsk(perm[k])) answerable.push(k)
    perm[k] = toAsk(perm[k])
  }
  return answerable
}
```

```python
"""OpenCode edition setup: copy opencode/ into one OpenCode config dir, record what was written, and remove it again.

Record: <dir>/dryas/install.json = {version, py, tiers, files: {rel: sha256}}. Setup refuses to overwrite a file it
did not write (not in the record, no dryas-managed marker, other content) and keeps a file the user edited after setup
as <file>.dryas-old before writing the new one. OpenCode loads plugin/, skill/, command/ and agent/ from the config dir
itself; the plugin adds the jev MCP server when OpenCode loads it, so opencode.json is never edited.
"""
import hashlib
import json
import os
import re
from pathlib import Path
from typing import Dict, List, Optional, Tuple

import dryas_install as di
import plugin_setup as ps

MIN_OPENCODE = (1, 18, 0)
RECORD = "dryas/install.json"
MARK = "<!-- dryas-managed -->"
TIERS = ("fast", "standard", "strong", "frontier")
SKIP_PARTS = ("__pycache__", ".pytest_cache")
LEGACY_SKILLS = (Path(".claude") / "skills", Path(".agents") / "skills")


def opencode_dir(arg: Optional[str]) -> Path:
    base = os.environ.get("XDG_CONFIG_HOME") or str(Path.home() / ".config")
    return ps.norm(arg or os.path.join(base, "opencode"))


def opencode_version(text: str) -> Optional[Tuple[int, ...]]:
    m = re.search(r"(\d+)\.(\d+)\.(\d+)", text or "")
    return tuple(int(x) for x in m.groups()) if m else None


def _sha(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()


def _version(repo: Path) -> str:
    return json.loads((Path(repo) / "claude/.claude-plugin/plugin.json").read_text(encoding="utf-8"))["version"]


def default_model(od: Path) -> str:
    """The top-level "model" of <dir>/opencode.json; "" when the file is missing, unreadable or JSONC."""
    try:
        v = json.loads((Path(od) / "opencode.json").read_text(encoding="utf-8")).get("model")
    except (OSError, ValueError, AttributeError):
        return ""
    return v if isinstance(v, str) else ""


def planned_files(repo: Path) -> Dict[str, Path]:
    """rel path under the config dir -> source file, for everything opencode/ ships."""
    base, out = Path(repo) / "opencode", {}
    for f in sorted(base.rglob("*")):
        rel = f.relative_to(base)
        if f.is_dir() or f.suffix == ".pyc" or any(p in SKIP_PARTS for p in rel.parts):
            continue
        out[rel.as_posix()] = f
    return out


def render(rel: str, data: bytes, models: Dict[str, str]) -> bytes:
    """Fill the model line of an executor agent; every other file is copied as it is."""
    m = re.fullmatch(r"agent/dryas-executor-(\w+)\.md", rel)
    if not m:
        return data
    model = models.get(m.group(1), "")
    text = data.decode("utf-8").replace("model: {{MODEL}}\n", ("model: %s\n" % model) if model else "")
    return text.encode("utf-8")


def _remove(od: Path, rel: str, sha: str) -> bool:
    """Delete a recorded file unless the user edited it; True when it is gone."""
    p = Path(od) / rel
    if not p.exists():
        return True
    if _sha(p.read_bytes()) != sha:
        return False
    p.unlink()
    d = p.parent
    while d != Path(od) and d.is_dir() and not os.listdir(str(d)):
        d.rmdir()
        d = d.parent
    return True


def _legacy_skill_warning(home: Path) -> None:
    names = ("brainstorm", "orchestrate", "worktree", "verify", "plan")
    for d in LEGACY_SKILLS:
        hits = [n for n in names if (home / d / n / "SKILL.md").is_file()]
        if hits:
            print("warning: OpenCode also loads %s, which holds %s; you may see two copies of these Dryas skills "
                  "(the OpenCode ones are named dryas-<name>)" % (home / d, ", ".join(hits)))


def setup(repo: Path, od: Path, comps: List[str], tiers: Dict[str, str], yes: bool, dry: bool = False) -> int:
    repo, od, root = Path(repo).resolve(), opencode_dir(str(od)), ps.data_root()
    rc, out = di.capture(["opencode", "--version"], timeout=60)
    ver = opencode_version(out) if rc == 0 else None
    if ver is None or ver < MIN_OPENCODE:
        print("error: Dryas needs OpenCode %s or newer (found: %s); nothing changed"
              % (".".join(map(str, MIN_OPENCODE)), out.strip() or "no opencode --version"))
        return 1
    rec = ps._load_json(od / RECORD, {})
    rec = rec if isinstance(rec, dict) else {}
    old = rec.get("files") if isinstance(rec.get("files"), dict) else {}
    chosen = dict(rec.get("tiers") or {}) if isinstance(rec.get("tiers"), dict) else {}
    chosen.update({t: m for t, m in (tiers or {}).items() if m})
    fallback = default_model(od)
    models = {t: chosen.get(t) or fallback for t in TIERS}
    want: Dict[str, bytes] = {}
    refused = []
    for rel, src in planned_files(repo).items():
        data = render(rel, src.read_bytes(), models)
        dest = od / rel
        if dest.is_file() and rel not in old:
            cur = dest.read_bytes()
            if cur != data and MARK.encode("utf-8") not in cur:
                refused.append(dest)
        want[rel] = data
    if refused:
        print("error: these files exist and were not written by Dryas; move them away and re-run (nothing changed):")
        for p in refused:
            print("  %s" % p)
        return 1
    if dry:
        print("would write %d files into %s" % (len(want), od))
        return 0
    written = {}
    for rel, data in want.items():
        dest = od / rel
        if dest.is_file() and rel in old and _sha(dest.read_bytes()) != old[rel] and dest.read_bytes() != data:
            keep = dest.with_name(dest.name + ".dryas-old")
            keep.write_bytes(dest.read_bytes())
            print("kept your edited %s as %s" % (dest, keep))
        dest.parent.mkdir(parents=True, exist_ok=True)
        dest.write_bytes(data)
        written[rel] = _sha(data)
    for rel in sorted(set(old) - set(written)):  # shipped by an older Dryas, not by this one
        if not _remove(od, rel, old[rel]):
            print("kept %s (edited after setup; no longer shipped)" % (od / rel))
    ps._save_json(od / RECORD, {"version": _version(repo), "py": str(di.PY).replace("\\", "/"), "tiers": chosen,
                                "files": written})
    ps.write_workflow_doc(repo, root)
    ps.write_chain_local(root, comps, None, repo, od)
    ps.add_account(root, od, "opencode_dirs")
    if len(set(models.values())) <= 1:
        print("warning: every executor tier runs on %s; set --tier-fast, --tier-standard, --tier-strong and "
              "--tier-frontier (provider/model) to give the ladder real steps" % (fallback or "OpenCode's default model"))
    _legacy_skill_warning(Path.home())
    print("Dryas set up in %s (state in %s). Restart OpenCode to load it." % (od, root))
    return 0


def uninstall(od: Path) -> int:
    od = opencode_dir(str(od))
    p = od / RECORD
    if not p.exists():
        return 0
    rec = ps._load_json(p, {})
    files = rec.get("files") if isinstance(rec, dict) and isinstance(rec.get("files"), dict) else {}
    kept = [rel for rel, sha in sorted(files.items()) if not _remove(od, rel, sha)]
    if p.exists():
        p.unlink()
    for d in (od / "dryas",):
        if d.is_dir() and not os.listdir(str(d)):
            d.rmdir()
    ps.remove_account(ps.data_root(), od, "opencode_dirs")
    for rel in kept:
        print("kept %s (edited after setup)" % (od / rel))
    print("uninstalled Dryas from %s" % od)
    return 0


def verify(od: Path, comps: List[str]) -> int:
    """PASS/FAIL lines for one OpenCode config dir; returns the number of FAILs."""
    od, fails = opencode_dir(str(od)), 0

    def say(status: str, name: str, detail: str = "") -> int:
        print("%s  %s%s" % (status, name, ("  (" + detail + ")") if detail else ""))
        return 1 if status == "FAIL" else 0

    rec = ps._load_json(od / RECORD, {})
    files = rec.get("files") if isinstance(rec, dict) and isinstance(rec.get("files"), dict) else {}
    fails += say("PASS" if files else "FAIL", "Dryas installed for OpenCode", str(od))
    if not files:
        return fails
    missing = [rel for rel in files if not (od / rel).is_file()]
    fails += say("FAIL" if missing else "PASS", "installed files present", ", ".join(missing[:3]))
    rc, out = di.capture(di.PYX + [str(od / "dryas/jev/rules_inject.py"), "--harness", "opencode"], "{}", timeout=60)
    try:
        ok = "Dryas paths:" in json.loads(out)["hookSpecificOutput"]["additionalContext"]
    except (ValueError, KeyError, TypeError):
        ok = False
    fails += say("PASS" if ok else "FAIL", "rules hook prints the OpenCode rules")
    fails += say("PASS" if di.scope_smoke(od / "dryas/jev/chain.py", {}, harness="opencode") else "FAIL",
                 "scope lock blocks an out-of-scope apply_patch")
    return fails
```

```python
"""OpenCode part of tools/release_check.py: checks one OpenCode config dir, read-only.
Hooks and the jev MCP server run with a temp data root (the sandbox env), never the user's ~/.dryas."""
import hashlib
import json
import re
import subprocess
import sys
import tempfile
from pathlib import Path
from typing import Optional, Tuple

REPO = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(REPO / "install"))
import dryas_install as di  # noqa: E402
import opencode_setup as ocs  # noqa: E402


def _rules_ok(od: Path, env: dict) -> bool:
    rc, out = di.capture(di.PYX + [str(od / "dryas/jev/rules_inject.py"), "--harness", "opencode"], "{}", env=env,
                         timeout=60)
    try:
        return "Dryas paths:" in json.loads(out)["hookSpecificOutput"]["additionalContext"]
    except (ValueError, KeyError, TypeError):
        return False


def _mcp_connected(opencode: str, od: Path, env: dict) -> Tuple[bool, str]:
    """`opencode mcp list` from a temp dir, with XDG_CONFIG_HOME pointing at od's parent when od is named opencode."""
    run_env = dict(env)
    if od.name == "opencode":
        run_env["XDG_CONFIG_HOME"] = str(od.parent)
    try:
        with tempfile.TemporaryDirectory() as d:
            r = subprocess.run([opencode, "mcp", "list"], cwd=d, env=run_env, capture_output=True,
                               universal_newlines=True, timeout=120)
    except (OSError, subprocess.TimeoutExpired) as e:
        return False, str(e)
    text = re.sub(r"\x1b\[[0-9;]*m", "", r.stdout + r.stderr)
    line = next((l for l in text.splitlines() if re.search(r"\bjev\b", l)), "")
    return ("connected" in line), (line.strip() or "jev not listed")


def check(rep, od: Path, opencode: Optional[str], env: dict) -> None:
    print()
    print("OpenCode: %s" % od)
    if not opencode:
        rep.say("SKIP", "Dryas for OpenCode", "opencode not on PATH")
        return
    try:
        rec = json.loads((od / ocs.RECORD).read_text(encoding="utf-8"))
    except (OSError, ValueError):
        rep.say("SKIP", "Dryas for OpenCode", "not set up in %s" % od)
        return
    rc, out = di.capture([opencode, "--version"], timeout=60)
    ver = ocs.opencode_version(out) if rc == 0 else None
    ok = ver is not None and ver >= ocs.MIN_OPENCODE
    rep.say("PASS" if ok else "FAIL", "OpenCode %s or newer" % ".".join(map(str, ocs.MIN_OPENCODE)), out.strip())
    files = rec.get("files") if isinstance(rec.get("files"), dict) else {}
    missing = [r for r in files if not (od / r).is_file()]
    edited = [r for r, sha in files.items() if (od / r).is_file()
              and hashlib.sha256((od / r).read_bytes()).hexdigest() != sha]
    rep.say("FAIL" if missing else "PASS", "installed files present", ", ".join(missing[:3]))
    rep.say("WARN" if edited else "PASS", "installed files unchanged",
            ("edited after setup: " + ", ".join(edited[:3])) if edited else "")
    ok, why = _mcp_connected(opencode, od, env)
    rep.say("PASS" if ok else "FAIL", "jev MCP server connects", why)
    rep.say("PASS" if _rules_ok(od, env) else "FAIL", "rules hook prints the OpenCode rules")
    rep.say("PASS" if di.scope_smoke(od / "dryas/jev/chain.py", {}, harness="opencode") else "FAIL",
            "scope lock blocks an out-of-scope apply_patch")
    models = set()
    for t in ocs.TIERS:
        p = od / ("agent/dryas-executor-%s.md" % t)
        m = re.search(r"^model:\s*(\S+)", p.read_text(encoding="utf-8"), re.M) if p.is_file() else None
        models.add(m.group(1) if m else "")
    rep.say("WARN" if len(models) <= 1 else "PASS", "executor tiers",
            "all tiers on one model; re-run setup with --tier-*" if len(models) <= 1 else "")
```
