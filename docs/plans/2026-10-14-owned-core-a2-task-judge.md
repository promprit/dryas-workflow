# Owned core, plan A2: task-level judge — Implementation Plan

> **For agentic workers:** run with `/orchestrate` on this file (Dryas). Each `## Task N:` section is self-contained: its Goal/Scope/Done/Failing-test lines are the `.orchestrate/PLAN.md` contract; Interfaces and Steps follow. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Judge the task, not only each edit: measure the baseline per task (Jev calls, gate wait, executor tokens and time, escalations, review findings), score each task and name its review set at dispatch, log both in shadow next to today's per-edit decisions, and add two evidence-gated switches (`review.task_skip`, `dispatch.scored_tier`, default off) that `/tune` proposes only when the logs show they are right; plus the local judge asks before commands that discard uncommitted work.

**Architecture:** `task_review.py` holds the path classes (always judged / plain), the content signals, the review set and the edit-time verdict read from `.orchestrate/active.json`; its CLI `task_review.py answer PLAN.md N` prints the answer the orchestrator writes into `active.json` and logs it. `task_score.py` computes the score (size, risk, tests, history) and its tier. `gate.py` logs `task_review`, `task_review_why` and `false_skip` on judged file edits and skips the judge only when `review.task_skip` is on. `log_dispatch` takes optional `score`, `score_tier`, `task_type`, `tokens`, `duration_ms`. `tune_tasks.py` builds per-task rows and the A2 report lines and proposals; `tune_window.py` makes the spec's "Done when" a computed PASS/FAIL against a baseline window. `local_judge._git` asks for `git checkout -- <path>`/`checkout .`, `git restore <path>` without `--staged`, `git stash clear`/`drop`. The scope lock denies executors every edit under `.orchestrate/`, also by shell.

## Decisions taken in this plan (spec ambiguities)

- **Field name.** The spec's `task_id` is the existing `task` field (`"<branch>:<N>"`), already on gate (A1), dispatch, escalation, review and merge records. No rename: FlowObserve and `/tune` read `task`. Gaps filled: the `task_review` verdict record carries `task`; review and merge records keep the branch name the skills already pass.
- **Usage goes on `log_dispatch`, not a new `log_return` tool** (coordinator item). The orchestrator calls `log_dispatch` once the Agent tool has returned, so the usage is in hand; one record per attempt keeps tokens and time keyed by task and attempt, which is exactly what "tokens wasted on failed attempts" needs; and a new tool would change `tools/list`, which `test_jev_mcp.py::test_tools_list` pins as an exact list (plan B already edits that line). §5.6 of the skill changes "right after every dispatch" to "when every dispatch returns".
- **Always-judged classes (approved by Promprit, 2026-10-14).** Always judged: dot paths, CI files by name, key/certificate suffixes, names containing `secret` or `credential`, everything the gate's `SENSITIVE_*` lists cover (build files by name and prefix, script suffixes), paths outside the worktree. There is no task-skippable "sensitive" class: `path_class` returns `always` or `plain`. A task verdict can skip only a plain file the plan names literally (a wildcard scope entry is always reviewed) whose new text has no content signal. Consequence: plain files inside the session's cwd are already skipped by `local_file`, so `review.task_skip` can only skip plain files in the worktree but outside the executor's cwd; its saving on file edits is small, and the A2 gain comes mainly from the measurements and the scored tier.
- **Local `task_review` answer.** Skip = scope entries without wildcards that are not always judged; review = everything else. Tier = the score's tier.
- **Score.** 0–100: size `3 × min(files, 10) + min(lines // 100, 20)`; risk 20 when a scope entry is always judged (build files and scripts included), else 0; tests 15 when no Done line runs a test; history `round(30 × escalation rate)` of the task type once `history.min_tasks` scored tasks of the type exist. Tier: < 30 `haiku`, < 60 `sonnet`, else `opus`. Task type = kinds of the scope entries (`docs`, `tests`, `code`, joined with `+`), computable at dispatch without the memory store. Escalation = an escalation record whose reason does not start with `skip-up`.
- **Where the verdict record goes.** Same JSONL files as today: `mcp.jsonl`, `tool: "task_review"`, with the spec's record fields (`task, question, provider, answer, confidence, shadow_provider, wall_ms, reasons`, plus `score`, `score_tier`, `task_type`). `tune.build` only reads `answers` (plural) from `mcp.jsonl`, so it does not count these as `jev_judge` questions.
- **Evidence rules.** False-skip rate = tasks with at least one false skip / tasks with at least one judged edit carrying a verdict (conservative: one false skip marks the task). `review.task_skip` is proposed on when that rate ≤ `review.max_false_skip_rate` over ≥ `review.min_tasks` tasks, and off when it no longer holds. "Score predicts escalation better" = over ≥ `dispatch.min_tasks` scored tasks, the score's tier equals the task's final tier more often than the start tier chosen by the tier questions did; proposed off again when it does worse. `/tune` proposes, `/tune apply` flips; nothing flips itself. Once `review.task_skip` is on, skipped edits are no longer judged, so new false skips can only come from edits still judged; the report shows `enforced skips` so the user can watch it.
- **"Every edit is still judged"** means judged as today: in-worktree, non-sensitive edits were already skipped by `local_file` (A1 and before) and stay so.
- **Done-when windows.** `baseline.until` (new threshold, `""` or `YYYY-MM-DD`): tasks first dispatched before it are the baseline. Empty: earlier half against later half. Fewer than 10 tasks in either window → `n/a`.

- Consumes: the existing parser: `_scan`, `_head`, `_bundles`, `_git(args)` (unchanged entry point; `args` are the words after `git`, quotes removed).
- Produces: `local_judge.destructive(cmd)` returns `git_checkout_discard`, `git_restore_discard` or `git_stash_drop` for those commands; `gate_answers("Bash", cmd)` → `decision "ask"`, `reasons ["destructive:<name>"]`. Rules: `checkout` asks when `--` is followed by at least one path, or when `.` is an operand (`-b`, `-B`, `--orphan` take a value). `restore` asks when it has a path operand and either no `--staged`/`-S` or also `--worktree`/`-W` (`-s`, `--source`, `--pathspec-from-file` take a value). `stash` asks when the first operand is `clear` or `drop`. Everything after `--` is an operand. No regex over the raw command.

def _operands(args: List[str], takes: Tuple[str, ...] = ()) -> List[str]:
    """Non-option words of a git subcommand; everything after "--" is an operand; an option in `takes`
    consumes the next word as its value."""
    out: List[str] = []
    i, n = 0, len(args)
    while i < n:
        a = args[i]
        if a == "--":
            return out + args[i + 1:]
        if a.startswith("-") and a != "-":
            i += 1 + (a in takes)
            continue
        out.append(a)
        i += 1
    return out


def _git_discard(sub: str, rest: List[str], flags: str) -> Optional[str]:
    """Commands that throw away uncommitted work or stashes (user decision 2026-10-14: always ask)."""
    if sub == "checkout":

            return "git_restore_discard"
        return None

"""Task review set (owned core A2): which files of a plan task need per-edit judgement, and the verdict the gate

The orchestrator writes the set into .orchestrate/active.json (the scope lock denies executors .orchestrate/):
  {"active": ["3"], "review_version": 1,
   "review": {"3": {"skip": ["src/a.py"], "review": ["src/**"], "tier": "sonnet", "score": 42}}}
An edit would be skipped only when it touches no always-judged path, its new text has no content signal, every
active task has a well-formed entry, some entry's skip list names the file and no entry's review list matches it.
Missing, unreadable, malformed or other-version data means the edit is judged (fail safe). Never raises.

CLI: task_review.py answer PLAN.md N   (prints the entry to write; see task_score.answer)"""

FILE_TOOLS = ("Write", "Edit", "MultiEdit", "NotebookEdit")
# Always judged, whatever a task verdict or provider says: dot paths (.git, .github CI, .env, .claude,
# .orchestrate), CI files by name, key and certificate files, secret-looking names, the gate's SENSITIVE_* build
# files and scripts, anything outside the worktree.
ALWAYS_NAMES = frozenset(("jenkinsfile", "azure-pipelines.yml", "bitbucket-pipelines.yml", "cloudbuild.yaml",
                          "cloudbuild.yml", ".gitlab-ci.yml"))
KEY_SUFFIXES = (".pem", ".key", ".crt", ".p12", ".pfx", ".jks", ".keystore", ".kdbx")
# Plain substrings of the new text (no regex): processes, eval, deletes, env reads, network.
CONTENT_SIGNALS = ("subprocess", "os.system", "os.popen", "child_process", "eval(", "exec(", "shutil.rmtree",
                   "os.remove", "unlink(", "rm -", "os.environ", "getenv", "process.env", "requests.", "urllib",
                   "http.client", "socket", "fetch(", "curl ", "wget ", "sudo ", "chmod ", "postinstall",
                   "preinstall")
MAX_TEXT = 1 << 20
_WILD = frozenset("*?[")


def _norm(rel: str) -> str:
    return posixpath.normpath(str(rel).replace("\\", "/"))


def always_judged(rel: str) -> bool:
    r = _norm(rel)
    if r in (".", "..") or r.startswith(("../", "/")):
        return True
    parts = [p for p in r.split("/") if p]
    if any(p.startswith(".") for p in parts):
        return True
    name = parts[-1].lower()
    if name in ALWAYS_NAMES or name.endswith(KEY_SUFFIXES) or "secret" in name or "credential" in name:
        return True
    import gate  # lazy: gate imports this module
    return gate._sensitive(r)  # build files and scripts (SENSITIVE_NAMES, _SENSITIVE_PREFIXES, SENSITIVE_SUFFIXES)


def path_class(rel: str) -> str:
    """"always" (always judged) or "plain"."""
    return "always" if always_judged(rel) else "plain"


def content_signal(text: str) -> Optional[str]:
    low = str(text)[:MAX_TEXT].lower()
    return next((s for s in CONTENT_SIGNALS if s in low), None)


def edit_text(tool: str, ti: Dict[str, Any]) -> str:
    if tool == "Write":
        return str(ti.get("content", ""))
    if tool == "NotebookEdit":
        return str(ti.get("new_source", ""))
    if tool == "MultiEdit":
        edits = ti.get("edits") if isinstance(ti.get("edits"), list) else []
        return "\n".join(str(e.get("new_string", "")) for e in edits if isinstance(e, dict))
    return str(ti.get("new_string", ""))

def review_set(globs: List[str]) -> Dict[str, List[str]]:
    """Local answer: a scope entry that names one file (no wildcard) and is not always judged may skip per-edit
    judgement; every other entry (wildcards, always-judged paths) stays reviewed."""
    out: Dict[str, List[str]] = {"skip": [], "review": []}
    for g in globs:
        g = g[2:] if g.startswith("./") else g
        literal = not (set(g) & _WILD)
        out["skip" if literal and path_class(g) != "always" else "review"].append(g)
    return out


def load_review(root: str) -> Optional[Dict[str, Dict[str, List[str]]]]:
    """The review set of every active task, or None when any part is missing or malformed."""
    try:
        with open(os.path.join(root, ".orchestrate", "active.json"), encoding="utf-8") as f:
            data = json.load(f)
        if not isinstance(data, dict) or data.get("review_version") != REVIEW_VERSION:
            return None
        active, review = data.get("active"), data.get("review")
        if not isinstance(active, list) or not active or not isinstance(review, dict):
            return None
        out: Dict[str, Dict[str, List[str]]] = {}
        for a in active:
            e = review.get(str(a))
            if not isinstance(e, dict) or not isinstance(e.get("skip"), list) or not isinstance(e.get("review"), list):
                return None
            if not all(isinstance(x, str) for x in e["skip"] + e["review"]):
                return None
            out[str(a)] = {"skip": e["skip"], "review": e["review"]}
        return out
    except Exception:
        return None


def edit_verdict(cwd: str, tool: str, ti: Dict[str, Any]) -> Optional[Tuple[str, str]]:
    """(verdict, why) for a file edit inside an orchestrated task, None outside one. verdict: "skip" (the task
    verdict would skip per-edit judgement), "review" or "unknown" (no usable review set: judged)."""
    try:
        if tool not in FILE_TOOLS or not taskctx.context(cwd):
            return None
        root = taskctx._root(cwd)
        if root is None:
            return None
        paths = targets(tool, ti)
        if not paths:
            return ("review", "no_path")
        base = os.path.realpath(cwd or ".")
        rels = [os.path.relpath(os.path.realpath(os.path.join(base, t)), root).replace(os.sep, "/") for t in paths]
        if any(always_judged(r) for r in rels):
            return ("review", "always")
        sig = content_signal(edit_text(tool, ti))
        if sig:
            return ("review", "content:" + sig)
        sets = load_review(root)
        if sets is None:
            return ("unknown", "no_review_set")

            if any(planfile.in_scope(r, e["review"]) for e in sets.values()):
                return ("review", "review_glob")
            if not any(planfile.in_scope(r, e["skip"]) for e in sets.values()):
                return ("review", "not_in_skip")
        return ("skip", "task_review")
    except Exception as e:
        return ("unknown", "error:" + type(e).__name__)

Shadow by default: the orchestrator writes it into the dispatch record and dispatches as before, unless
dispatch.scored_tier is on. Points (0-100):
  size     3 per file in scope (max 10 files) + 1 per 100 lines in those files (max 20)
  risk     20 if a scope entry is always judged (dot paths, CI, keys, secrets, build files, scripts)
  tests    15 when no Done line runs a test
  history  30 x the escalation rate of this task type, only once history.min_tasks scored tasks of the type exist
Tier: under 30 haiku, under 60 sonnet, else opus. Stdlib only; reads files in scope, never raises from answer()."""

MAX_BYTES = 2 << 20

                       ".mypy_cache", ".pytest_cache"))
TEST_WORDS = ("pytest", "unittest", "jest", "vitest", "mocha", "go test", "cargo test", "swift test", "npm test",
              "pnpm test", "yarn test", "rspec", "phpunit", "ctest", "make test", "tox", "nox")

def done_lines(section: str) -> List[str]:
    out: List[str] = []
    inside = False
    for line in section.splitlines():
        if line.startswith("Done:"):
            inside = True
            continue
        if inside:
            s = line.strip()
            if s.startswith("- "):
                out.append(s[2:])
            elif s:
                break
    return out


def runs_test(section: str) -> bool:
    return any(w in line.lower() for line in done_lines(section) for w in TEST_WORDS)


def task_type(globs: List[str]) -> str:
    kinds = set()
    for g in globs:
        low = g.lower()
        if low.endswith((".md", ".rst", ".txt")) or low.startswith("docs/"):
            kinds.add("docs")
        elif "test" in low:
            kinds.add("tests")
        else:
            kinds.add("code")
    return "+".join(sorted(kinds)) or "none"


def _lines(path: str) -> int:
    try:
        with open(path, "rb") as f:
            return f.read(MAX_BYTES).count(b"\n")
    except OSError:
        return 0


def scope_size(root: str, globs: List[str]) -> Tuple[int, int]:
    """(files, lines) in scope. A wildcard-free entry that does not exist yet counts as one empty file."""
    files = lines = seen = 0
    found = set()
    for d, dirs, names in os.walk(root):
        dirs[:] = sorted(x for x in dirs if x not in SKIP_DIRS)
        for name in sorted(names):
            seen += 1
            if seen > MAX_FILES:
                break
            rel = os.path.relpath(os.path.join(d, name), root).replace(os.sep, "/")
            if planfile.in_scope(rel, globs):
                files += 1
                lines += _lines(os.path.join(d, name))
                found.add(rel)
        if seen > MAX_FILES:
            break
    new = {g[2:] if g.startswith("./") else g for g in globs if not set(g) & set("*?[")}
    return files + len(new - found), lines


def history(ttype: str, min_tasks: int, log_dir: Optional[str] = None) -> Optional[float]:
    """Escalation rate of scored tasks of this type (skip-ups are start tiers, not escalations), or None below
    min_tasks tasks."""
    types: Dict[str, str] = {}
    escalated = set()
    d = log_dir or jevlog.log_dir()
    for name in ("mcp", "escalations"):
        try:
            with open(os.path.join(d, name + ".jsonl"), encoding="utf-8") as f:
                for line in f:
                    try:
                        r = json.loads(line)
                    except ValueError:
                        continue
                    if not isinstance(r, dict) or not isinstance(r.get("task"), str):
                        continue
                    if name == "mcp" and r.get("tool") == "task_review" and isinstance(r.get("task_type"), str):
                        types[r["task"]] = r["task_type"]
                    elif name == "escalations" and not str(r.get("reason", "")).startswith("skip-up"):
                        escalated.add(r["task"])
        except OSError:
            continue
    mine = [t for t, k in types.items() if k == ttype]
    if len(mine) < min_tasks:
        return None
    return sum(1 for t in mine if t in escalated) / len(mine)


def tier(score: int) -> str:
    return next((name for limit, name in TIERS if score < limit), "opus")


def bucket(score: int) -> str:
    return next((name for limit, name in BUCKETS if score < limit), "60-100")


def score(files: int, lines: int, classes: List[str], has_test: bool, hist: Optional[float]) -> Dict[str, int]:
    parts = {"size": min(files, 10) * 3 + min(lines // 100, 20),
             "risk": 20 if "always" in classes else 0,
             "tests": 0 if has_test else 15,
             "history": round(hist * 30) if hist is not None else 0}
    parts["total"] = min(100, sum(parts.values()))
    return parts


def answer(root: str, section: str, task_id: str, th: Dict[str, Any], log_dir: Optional[str] = None) -> Dict[str, Any]:
    """The task_review answer for one plan section: review set, score, tier and task type."""
    globs = planfile.scope(section)
    ttype = task_type(globs)
    files, lines = scope_size(root, globs)
    hist = history(ttype, th["history"]["min_tasks"], log_dir)
    parts = score(files, lines, [task_review.path_class(g) for g in globs], runs_test(section), hist)
    rs = task_review.review_set(globs)
    return {"task": task_id, "skip": rs["skip"], "review": rs["review"], "score": parts["total"],
            "tier": tier(parts["total"]), "task_type": ttype, "parts": parts, "files": files, "lines": lines,
            "history": hist}

    judge.calls = calls
    return judge

import math
import statistics
from collections import Counter
from typing import Any, Dict, List, Optional

FILE_TOOLS = ("Write", "Edit", "MultiEdit", "NotebookEdit")
RANK = {"haiku": 0, "sonnet": 1, "opus": 2, "fable": 3}
BUCKETS = ((30, "0-29"), (60, "30-59"))


def _n(v: Any) -> Optional[float]:
    if isinstance(v, bool) or not isinstance(v, (int, float)):
        return None
    return float(v) if math.isfinite(v) and v >= 0 else None


def _ids(r: Dict[str, Any]) -> List[str]:
    one = [r["task"]] if isinstance(r.get("task"), str) else []
    many = [t for t in (r.get("tasks") if isinstance(r.get("tasks"), list) else []) if isinstance(t, str)]
    return list(dict.fromkeys(one + many))


def bucket(score: float) -> str:
    return next((name for limit, name in BUCKETS if score < limit), "60-100")

    last_role: Dict[str, Dict[str, Any]] = {}
    for r in (x for x in dispatch if isinstance(x, dict) and isinstance(x.get("task"), str)):
        row = out.setdefault(r["task"], _row())
        tier = r.get("tier") if r.get("tier") in RANK else None
        if row["start_tier"] is None or (r.get("role") == "coder" and not row.get("_coder")):

            row["final_tier"] = tier

            row["wasted_tokens"] += prev
        last_role.setdefault(r["task"], {})[r.get("role")] = tok or 0.0
        if _n(r.get("score")) is not None and r.get("score_tier") in RANK:

        if isinstance(r.get("ts"), str) and (row["first_ts"] is None or r["ts"] < row["first_ts"]):

            row["judge_spend"] += (_n(r.get("cost")) or 0.0) + (_n(r.get("shadow_cost")) or 0.0)

           for k in ("tokens", "duration_ms", "jev_calls", "judge_spend", "gate_wait_ms")}

    for tier in sorted({r["start_tier"] for r in rs if r["start_tier"]}, key=RANK.get):
        mine = [r for r in rs if r["start_tier"] == tier]

            _n(r.get(k)) or 0.0 for k in ("critical", "important", "minor"))
    scored = [r for r in rs if r["score"] is not None and r["final_tier"]]
    buckets: Dict[str, Dict[str, int]] = {}
    for r in scored:
        b = buckets.setdefault(bucket(r["score"]), {"tasks": 0, "escalated": 0})
        b["tasks"] += 1
        b["escalated"] += r["escalated"]
    with_set = [r for r in rs if r["review_edits"]]
    return dict(
        tasks=len(rs), per_task=per, by_tier=by_tier,
        wasted_tokens=sum(r["wasted_tokens"] for r in rs),
        edits=len(edits),
        deny_per_edit=round(sum(1 for r in edits if r.get("decision") == "deny") / len(edits), 4) if edits else None,
        ask_per_edit=round(sum(1 for r in edits if r.get("decision") == "ask") / len(edits), 4) if edits else None,

        tier_accuracy=round(sum(r["start_tier"] == r["final_tier"] for r in scored) / len(scored), 4) if scored else None,

        enforced_skips=sum(1 for r in gate if isinstance(r, dict) and r.get("via") == "task_review"))

def proposals(s: Dict[str, Any], th: Dict[str, Dict[str, Any]]) -> List[Dict[str, Any]]:

        ok = rate <= rv["max_false_skip_rate"]
        if ok != rv["task_skip"]:
            out.append({"key": "review.task_skip", "old": rv["task_skip"], "new": ok,
                        "why": "false-skip rate %s over %d tasks with a review set (max %s)"
                               % (_pct(rate), s["review_tasks"], _pct(rv["max_false_skip_rate"]))})
    sa, ta = s["score_accuracy"], s["tier_accuracy"]
    if s["scored_tasks"] >= dp["min_tasks"] and sa is not None and ta is not None:

                               % (_pct(sa), s["scored_tasks"], _pct(ta))})

                        "why": "scored start tiers were right for %s of %d tasks, below %s" % (_pct(sa), s["scored_tasks"], _pct(ta))})
    return out

"""The spec's "Done when" check for task-level judgement (owned core A2), computed by /tune: a baseline window of
tasks against the current window, per task (medians), with PASS or FAIL per line.
  Jev calls per task      current <= half of baseline
  Gate wait per task      current < baseline (both 0 passes)
  Executor tokens / task  current <= baseline
  Escalation rate         current <= baseline
Windows: tasks first dispatched before thresholds baseline.until (YYYY-MM-DD) against the rest, or, when it is "",
the earlier half of the logged tasks against the later half (ordered by first dispatch time). A window with fewer
than WINDOW_MIN tasks gives n/a."""
import statistics
from typing import Any, Dict, List, Optional, Tuple

WINDOW_MIN = 10
Rows = Dict[str, Dict[str, Any]]


def windows(task_rows: Rows, until: str) -> Tuple[List[Dict[str, Any]], List[Dict[str, Any]]]:
    timed = sorted((r for r in task_rows.values() if isinstance(r.get("first_ts"), str)), key=lambda r: r["first_ts"])
    if until:
        return [r for r in timed if r["first_ts"] < until], [r for r in timed if r["first_ts"] >= until]
    half = len(timed) // 2
    return timed[:half], timed[half:]


def _median(rows: List[Dict[str, Any]], key: str) -> Optional[float]:
    vals = [r[key] for r in rows if r.get(key) is not None]
    return float(statistics.median(vals)) if vals else None


def _rate(rows: List[Dict[str, Any]]) -> Optional[float]:
    return sum(1 for r in rows if r.get("escalated")) / len(rows) if rows else None


CHECKS = (
    ("Jev calls per task", "jev_calls", "at most half", lambda b, c: c <= b / 2),
    ("Gate wait per task (ms)", "gate_wait_ms", "lower", lambda b, c: c < b or b == c == 0),
    ("Executor tokens per task", "tokens", "no higher", lambda b, c: c <= b),
    ("Escalation rate", None, "no higher", lambda b, c: c <= b),
)


def check(task_rows: Rows, until: str) -> Dict[str, Any]:
    base, cur = windows(task_rows, until)
    out = {"basis": ("before %s" % until) if until else "earlier half", "base_tasks": len(base),
           "current_tasks": len(cur), "lines": []}
    enough = len(base) >= WINDOW_MIN and len(cur) >= WINDOW_MIN
    for name, key, target, ok in CHECKS:
        b = _median(base, key) if key else _rate(base)
        c = _median(cur, key) if key else _rate(cur)
        verdict = "n/a" if not enough or b is None or c is None else ("PASS" if ok(b, c) else "FAIL")
        out["lines"].append({"name": name, "base": b, "current": c, "target": target, "verdict": verdict})
    return out


def _v(x: Optional[float]) -> str:
    return "n/a" if x is None else ("%.2f" % x).rstrip("0").rstrip(".")

## Task-level judgement

At dispatch the orchestrator runs `jev/task_review.py answer` for each task. The answer is local and deterministic: a **review set** (scope entries that name one file and are not always judged may skip per-edit judgement; wildcard entries stay reviewed), a **score** from 0 to 100 (size: files and lines in scope; risk: path classes; tests: whether a Done line runs a test; history: the escalation rate of this task type, counted only once `history.min_tasks` scored tasks of the type exist) and the start tier the score would pick. The score goes into the dispatch record, together with the executor's tokens and duration.

Both run in shadow first. The gate logs the task verdict (`task_review`, `task_review_why`) next to every judged edit inside a task and logs `false_skip` when the deciding or shadow answer said deny or ask on a file the task verdict would have skipped. Two switches in thresholds, both off by default, act on the evidence:

- `review.task_skip`: the gate skips per-edit judgement on a file the task verdict skips. `/tune` proposes it when the share of tasks with a false skip is at most `review.max_false_skip_rate` (0.01) over at least `review.min_tasks` (50) tasks with a review set, and proposes turning it off when that stops holding.
- `dispatch.scored_tier`: the orchestrator starts a task on the score's tier instead of the tier questions. `/tune` proposes it when, over at least `dispatch.min_tasks` (50) scored tasks, the score picked the tier that finished the task more often than the tier questions did.

`/tune` reports per task the executor tokens and time, Jev calls, judge spend and gate wait (medians, and per start tier medians and p90), tokens of failed attempts, deny and ask rate per edit, escalation rate, review findings, score buckets against escalations and false skips.
