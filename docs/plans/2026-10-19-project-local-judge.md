# Project-local judge — Implementation Plan

> **For agentic workers:** run with `/orchestrate` on this file (Dryas). Each `## Task N:` section is self-contained: its Goal/Scope/Done/Failing-test lines are the `.orchestrate/PLAN.md` contract; Interfaces and Steps follow. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A committed `.dryas-judge` marker at a project root keeps every judge call for sessions at or below that folder on the local judge, so no judge data from that project (first user: `projects/VOID`) reaches OpenRouter.
**Architecture:** A new `claude/jev/judge_policy.py` finds the marker by walking up from the session's directory (fail closed, cached). `providers.resolve` consults it first and every caller passes its `cwd` (policy A); `jev_client.judge` refuses to send when the marker is found (guard B). `handoff.build_handoff` starts respecting the provider, which also closes the global `judge.provider: local` hole for `/handoff` and compaction.
**Tech Stack:** Python 3.9 stdlib, `unittest`/pytest, existing Dryas hook chain and sync tools.
**Spec:** `docs/specs/2026-10-19-project-local-judge-design.md`

## Global Constraints

- Python 3.9 stdlib only in `claude/jev/`; no new dependency.
- No new prompts, no new allow rule, no change to any account's `settings.json`.
- Without a marker, behaviour and log lines are what they are today (exception: `/handoff` and compaction with a local provider, section "Task 4").
- Any marker means local: content `local`, any other content, empty, unreadable, or a directory named `.dryas-judge`.
- New log field `"judge_policy": "project_local"`, only when the marker decided. `provider` stays `"local"`. `fallback` is not written for a policy decision; fallbacks keep exactly `"fallback": "local"`.
- New `jev_ok` value `"local"` in `handoff.jsonl`/`compact.jsonl` whenever the provider was local.
- Files stay under 500 lines.
- Tests run with `python3 -m pytest -q claude/jev/tests`; the whole suite must stay green.
- Never work around the live Jev gate: put dangerous-looking strings in test files, never obfuscate them in commands.
- Change `claude/jev` only; `codex/` and `opencode/` are regenerated by the sync tools in Task 5.

## Review Focus

1. A session `cwd` reached through a symlink into a marked project: expected local (lookup resolves `realpath` first).
2. A `cwd` that is a file, not a folder (`NotADirectoryError` on `<file>/.dryas-judge`): expected no crash, the walk continues to the parents.
3. A `.dryas-judge` that is a directory, or a broken symlink: expected local (`lstat` succeeds).
4. A judge state whose `cwd` is not a string (`None`, a number, a list): expected the process directory is used, no crash.
5. The walk at the filesystem root (`os.path.dirname("/") == "/"`, `"C:\\"` on Windows): expected it stops, never loops.

```python
"""Project-local judge policy (docs/specs/2026-10-19-project-local-judge-design.md).

A committed `.dryas-judge` file at a project root keeps every judge call for sessions at or below that folder on
the local judge. Any marker means local, whatever it holds; the file is never read. An unexpected error while
looking counts as a marker (fail closed). Results are cached per start folder for the life of the process."""
import os
from typing import Dict, Optional

MARKER = ".dryas-judge"
_cache: Dict[str, bool] = {}


def clear_cache() -> None:
    _cache.clear()


def _start(cwd: Optional[str]) -> Optional[str]:
    if isinstance(cwd, str) and cwd:
        return cwd
    try:
        return os.getcwd()
    except OSError:
        return None


def _marked(folder: str) -> bool:
    try:
        os.lstat(os.path.join(folder, MARKER))
        return True
    except (FileNotFoundError, NotADirectoryError):
        return False
    except OSError:  # e.g. a parent without search permission: fail closed
        return True


def project_local(cwd: Optional[str] = None) -> bool:
    start = _start(cwd)
    if start is None:
        return False
    folder = os.path.realpath(start)
    hit = _cache.get(folder)
    if hit is not None:
        return hit
    cur, hit = folder, False
    while True:
        if _marked(cur):
            hit = True
            break
        parent = os.path.dirname(cur)
        if parent == cur:
            break
        cur = parent
    _cache[folder] = hit
    return hit
```

```python
#!/usr/bin/env python3
"""Time judge_policy.project_local at a VOID-like depth: cold (fresh cache) and cached. Spec 2026-10-19 §7.
  python3 tools/bench_judge_policy.py [--n 2000]"""
import argparse
import os
import shutil
import statistics
import sys
import tempfile
import time
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "claude" / "jev"))
import judge_policy  # noqa: E402


def main() -> int:
    p = argparse.ArgumentParser()
    p.add_argument("--n", type=int, default=2000)
    n = p.parse_args().n
    tmp = tempfile.mkdtemp()
    try:
        start = os.path.join(tmp, "VOID", "Pilot", ".claude", "worktrees", "x", "src")
        os.makedirs(start)
        Path(tmp, "VOID", ".dryas-judge").write_text("local\n", encoding="utf-8")
        cold, warm = [], []
        for _ in range(n):
            judge_policy.clear_cache()
            t0 = time.perf_counter()
            judge_policy.project_local(start)
            cold.append((time.perf_counter() - t0) * 1e6)
            t0 = time.perf_counter()
            judge_policy.project_local(start)
            warm.append((time.perf_counter() - t0) * 1e6)
        c, w = statistics.median(cold), statistics.median(warm)
        print("cold p50 %.1f us, cached p50 %.2f us (n=%d)" % (c, w, n))
        ok = c < 1000 and w < 10
        print("PASS" if ok else "FAIL")
        return 0 if ok else 1
    finally:
        shutil.rmtree(tmp, ignore_errors=True)


if __name__ == "__main__":
    sys.exit(main())
```
